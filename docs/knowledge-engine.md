# Knowledge Engine

## Status

- **Implemented:** organization-scoped lessons, explicit reuse records, applicability matching, knowledge-growth and reuse metrics, and Belief Graph lesson edges.
- **Verified locally:** existing lifecycle and organization-boundary fixtures plus Release 1.0 type and unit validation.
- **Planned:** semantic retrieval, knowledge governance UI, conflict resolution, expiry, source-document ingestion, and cross-case pattern analysis.

MerchantFlare reuses only lessons from the same organization. A lesson retains the originating outcome, applicability, limitations, confidence, and source Decision Case. Reuse creates a new link; it does not copy or rewrite history.

Knowledge growth counts durable lessons. Knowledge reuse counts explicit reuse records. Neither metric estimates value from chat volume or generated text.
